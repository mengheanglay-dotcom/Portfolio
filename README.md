# Lay Mengheang — Portfolio (React + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Edit your content in `src/data.js`:
- `profile.email`, `profile.photo` (put the image in `/public`, e.g. "/photo.jpg"), `github`, `linkedin`
- each project's `url` — paste your live website link and a "Visit website" button appears
